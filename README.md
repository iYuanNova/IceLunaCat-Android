# IceLunaCat

基于 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 构建的多渠道 AI 客户端。保留 MIT 许可与上游源码，复用上游 Markdown（公式、代码、Mermaid）渲染和 SSE 解码器，新增独立 Studio 界面、API 适配层与本地工作区。

## 核心功能

### 多渠道与模型管理
- **多渠道隔离配置**：支持在「设置 → 对话 API」与「设置 → 生图 API」中添加多个独立渠道，分别保存接口地址、API Key、协议类型、温度、Token 上限、思考等级与搜索服务。
- **自动模型发现与搜索**：填写地址与密钥后自动拉取并缓存模型列表（支持 OpenAI / Anthropic 风格 `/models` 与分页，5 分钟内复用缓存，按接口、协议与密钥隔离缓存，支持手动刷新与手动添加）。顶部模型菜单按渠道分组，支持跨渠道搜索名称与 ID、键盘方向键导航与 Enter 选择（交互参考 [DeepSeek Harness 模型选择器](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/client/ui-model-selection)）。
- **模型上限自适应**：优先使用接口返回的 `context_window`、`context_length`、`max_input_tokens`、`max_output_tokens`、`max_tokens` 等限制字段；接口未返回时回退至内置规格或 1M 预设，并支持关闭「自动使用模型上限」手动调整（未选择模型时默认 1M，发送前需先选定模型）。
- **独立会话绑定与模型溯源**：每个对话独立记录选用的模型与渠道，新对话默认沿用最近选中的模型；每条助手回复底部均记录实际使用的模型 ID（文字与生图均支持，旧版历史显示「历史模型未记录」），切换全局模型不影响旧记录。

### 对话体验与上下文管理
- **完整流式与推理展示**：支持 SSE 流式回复、思考内容（`reasoning_content` 与 Anthropic `thinking` 事件）折叠展示、停止生成、重试以及 Markdown、代码、公式和 Mermaid 渲染。
- **思考等级调节**：根据模型元数据动态生成思考等级滑杆（支持 DeepSeek、OpenRouter 等服务），支持拖拽吸附、键盘逐档微调与一键重置（样式参考 [ABING1111/dsh-codex-model-effort-selector](https://github.com/ABING1111/dsh-codex-model-effort-selector)）。
- **多模态图片对话**：支持点击输入框「＋」、粘贴或拖入上传图片（每条消息最多 8 张，支持 PNG、JPEG、WebP、GIF；图片文件大小取决于设备可用空间与 API 服务限制），支持预览、移除或纯图片发送，点击可放大查看。未压缩历史中的上传图与生成图会随上下文一并发送（需搭配支持视觉输入的模型与服务使用）。
- **对话分支**：在任意已完成的助手回复底部点击「创建分支」，可复制截至该节点的消息及当前人设、世界书生成独立新对话（从压缩检查点前创建分支时自动恢复对应原始消息上下文），顶部支持返回原对话，删除原对话不影响分支保留。
- **上下文压缩**：对话超过两轮后，可使用「压缩上下文」调用当前对话模型总结较早消息（同时摘要早期图片可见内容，保留最近两轮原文），支持查看/修改摘要或随时恢复完整上下文。

### 人设、世界书与个性化
- **独立人设与世界书**：每个对话拥有独立的助手人设、用户人设、世界书与压缩摘要（新对话默认空白，互不干扰）。世界书支持「禁用」、「始终注入」或「关键词触发」（匹配最近 6 条消息与当前输入，不区分大小写，关键词用逗号或换行分隔）。
- **界面定制**：支持自定义用户与助手名称及头像、明暗/系统主题、自定义背景图与遮罩透明度调节，适配移动端侧栏与自适应布局。

### 独立文生图与联网搜索
- **文生图工作流**：在「设置 → 生图 API」独立配置 OpenAI Images 兼容服务（生图模型初始为空，默认尺寸为 Auto，选定模型后即可生成）。切换至「生成图片」模式后，顶部模型选择器切换为生图模型列表，支持选择尺寸与质量，支持 JSON 返回与 SSE 渐进式流式预览，实时显示生成耗时。
- **联网搜索集成**：输入框可按需开启「联网搜索」，在「设置 → 联网搜索」中选择自动识别官方搜索能力（DeepSeek、OpenRouter、Claude、OpenAI 专用搜索模型）或配置独立的 Tavily API（支持基础与深入搜索，搜索结果与引用链接随消息保存）。

### 本地存储与数据备份
- **本地持久化**：使用 IndexedDB 持久保存聊天记录、密钥、未发送草稿、图片、头像、背景与所有设置，支持聊天搜索、重命名与删除。
- **工作区备份与恢复**：在数据管理中导出与导入完整工作区 JSON 备份（默认不包含对话与搜索 API 密钥，可按需勾选导出；兼容旧版 JSON 备份导入）。

## 快速上手

1. **配置对话模型**：打开应用后按引导配置，或进入右上角「设置 → 对话 API」，选择 OpenAI Chat Completions 或 Anthropic Messages 协议，填写接口地址与 API Key 后在列表中选定模型。
2. **定制人设与外观**：在「设置 → 个人形象 / 外观与背景」中设置头像、名称、主题与背景；在右上角「人设与世界书」中为当前对话配置角色设定。
3. **开始对话**：支持文本输入与图片上传；对话超过两轮后可使用「压缩上下文」节省 Token，或在任意回复处创建分支探索不同走向。
4. **文生图与搜索**：在设置中配置「生图 API」或「联网搜索」后，即可在输入框切换生图模式或按需开启联网检索。

## 本地运行与构建

从源码运行前，先安装依赖并生成构建产物：

```bash
pnpm install --frozen-lockfile
pnpm build
```

### 打包 Android 应用

生成 `dist/` 后，按[根目录的 Android 构建说明](../README.md#android)编译并签名 APK。

### 开发与检查命令

```bash
pnpm dev      # 启动本地开发服务器
pnpm build    # 构建生产版本至 dist/
pnpm type     # 执行 TypeScript 类型检查
```

## API 兼容范围

- **对话接口**：支持 `/v1/chat/completions`（OpenAI SSE / 非流式 JSON）与 `/v1/messages`（Anthropic SSE / 非流式 JSON），地址可填写服务根路径、带版本号路径或完整接口路径，支持 `reasoning_content` 与 Anthropic `thinking` 事件。
- **生图接口**：支持 `/v1/images/generations`（OpenAI 兼容鉴权），支持返回 `data[0].b64_json`、`data[0].url`，以及 OpenAI `image_generation.partial_image` / `image_generation.completed` SSE 事件（流式预览需目标接口支持）。
- **暂不支持**：自定义的非兼容任务轮询协议、仅支持 Responses 的服务、图生图编辑以及非图片附件。

## 注意事项与限制

- **跨域与 HTTPS**：所有请求均由客户端直接发起（无服务端代理），目标接口必须允许跨域请求（CORS）；若页面运行在 HTTPS 环境下，接口地址也必须使用 HTTPS。
- **本地存储与密钥安全**：数据按运行来源隔离存储，不跨设备同步；清理缓存、无痕模式结束或设备存储空间不足会影响保存，请定期导出备份。API Key 以明文保存在本地，备份勾选「包含 API 密钥」后也会包含明文密钥，请妥善保管。
- **远程图片链接有效期**：URL 格式的生成图会尝试下载并转存至本地；若目标服务器限制跨域下载则仅保留远程 URL，原链接过期后将无法查看，建议及时下载保存。
- **Token 估算与计费**：输入框底部显示跨模型 Token 估算值（中日韩字符约 1.5 Token，其余约 4 字符/Token，图片暂按每张约 1600 Token 预留），实际消耗以供应商返回为准。压缩上下文与联网搜索均会消耗对应服务商的额度。

## 目录结构
